# 💫 About Me

I'm a software engineer with 1.5 years of experience building AI and full-stack systems. I specialize in agentic applied AI: conversational voice AI, coding agents, multi-agent systems, evaluation pipelines, and the infrastructure that makes them reliable, measurable and fast. I also work across full-stack engineering, DevOps and security.

I'm a problem solver first. I like taking a system apart to understand why it works, learning new tools by building real things with them, and following a problem from the infrastructure all the way up to the product.

I'm a Software Engineer at The Product Highway, and before that I worked at For Real and Sopra Banking Software. Some of what I've done:

- **Cut voice-AI latency by about 45%**, saving about 1.75 s per spoken message for US users on real traffic, with Redis tool caching on top.
- **Fine-tuned a model to predict tool calls**, served on GPU at 28 ms: exact tool selection rose from 0/50 to 18/50 and LLM calls per step fell 42%.
- **Built a voice-and-text shopping assistant** into a live storefront, calling server tools and on-page actions from live page and cart context.
- **Architected a marketplace's order lifecycle** in MedusaJS, from exchanges and partial cancellations to fulfilment, with sagas, idempotency and retries.
- **Handled DevOps end to end**, designing CI/CD pipelines and deployments with GitLab CI, Docker, Helm, Kubernetes and AWS, which cut release time by 60%.
- **Owned Open Banking APIs end to end**, from design decisions to QA, reaching QWAC/QSEAL compliance with HSM-managed keys, JWE encryption and OAuth/mTLS.

My notes on AI, system design, security, Kubernetes, Docker and more live on my portfolio.
